You can chat with GitLaw Agent to review a draft document using plain-language instructions through the following steps:

### **Steps**

1.  **Upload a contract or paste the clause:** To review a document, you may need to upload a file or paste the text into the chat.
    a. Accepted file formats: DOCX, PDF, MD, HTML
    b. File size: maximum 5 MB per file, up to 5 files per message
    ***
2.  **Ask for a summary:** You can choose the **Review a document** option or request a plain language summary or explanation of specific clauses (“Summarize this confidentiality section”).
    ***
3.  **Identify issues:** Ask the Agent to flag missing sections, contradictory terms or clauses that might be problematic. For example, “Review this contract and highlight any missing termination provisions.”
    ***
4.  **Review and iterate:** Based on the Agent explanation, you can iterate on the document to make tweaks, fix issues by prompting in plain language.

### **Best practices for working with GitLaw Agent**

1.  **Be specific:** Provide clear instructions and important details to get the best results. Vague requests may require multiple refinements.

2.  **Verify outputs:** The Agent is based on trusted templates, but you should always review the draft for legal accuracy and compliance with local laws. Involve a human lawyer if necessary.

3.  **Iterate:** Use the chat to refine the document. Ask follow‑up questions or request alternative language until the document meets your needs.

4.  **Maintain contractual confidentiality:** GitLaw stores data securely, but you are responsible for complying with your contractual obligations.

5.  **Leverage version control:** When saving the document, take advantage of GitLaw’s versioning features to track changes and collaborate with others.
