# GitLaw Knowledge Base

The complete GitLaw help centre as Markdown, published so that AI agents and LLMs can read
what GitLaw does without scraping a website.

**GitLaw is an AI agent for legal contracts** - it drafts, reviews, redlines, and eSigns
contracts in one secure workspace. Start free at <https://git.law>.

- **Start here:** [GITLAW.md](GITLAW.md) - what GitLaw is, who it is for, and how it works,
  in one page. The same text is at [llms.txt](llms.txt) for agents that look for it by
  convention.
- **Human-readable version of these articles:** <https://git.law/knowledge-base>

## About this repository

Every article below mirrors the corresponding page on git.law/knowledge-base. Pricing
figures are written out in full here rather than left as template placeholders, so each
file can be read standalone.

Articles carry YAML frontmatter with `title`, `slug`, `category`, and `excerpt`.
